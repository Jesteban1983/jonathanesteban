## Reglas
- Título: ≤ 60 caracteres, keyword + ciudad. Descripción: 140–165 caracteres con CTA.
- No crear páginas por municipio hasta tener contenido propio y útil (evitar *doorway pages*).
- Cada servicio enlaza a 2–3 recursos relacionados (bloque «Te puede interesar»); cada artículo enlaza a sus servicios.
