Estudio de Caso #2

TrackFlow: Sistema Logístico & Inventario

Diseño e implementación de API REST robusta para control de stock multi-almacén (LA & ZGZ) y panel backoffice.

El Desafío

Empresas de distribución requieren control preciso en tiempo real de entradas, salidas y cálculos de stock por almacén con endpoints protegidos por JWT.

Arquitectura Desarrollada

Construido con Python 3, FastAPI, esquemas Pydantic v2, ORM SQLModel sobre PostgreSQL en Supabase y dashboard administrativo en Next.js.

Stack Tecnológico

Python 3 FastAPI Pydantic v2 SQLModel PostgreSQL (Supabase) Next.js JWT Swagger/OpenAPI Docker GitHub Actions

Endpoints de la API

  • POST /api/auth/login — Autenticación JWT
  • GET /api/almacenes — Listado multi-almacén (LA, ZGZ)
  • POST /api/inventario/movimiento — Registrar entrada/salida
  • GET /api/inventario/stock?almacen=X — Consulta de stock en tiempo real
  • GET /api/reportes/diario — Reporte agregado

Características Clave

  • Control de stock concurrente con transacciones SQL
  • Esquemas Pydantic v2 con validación estricta
  • Cache de consultas frecuentes con Redis
  • Dashboard Next.js con Server Components
  • Documentación interactiva con Swagger UI

Resultados

  • Reducción de errores de inventario en un 95%
  • Consultas de stock en <50ms
  • Dashboard operativo en tiempo real
  • API ready para integración con sistemas ERP
