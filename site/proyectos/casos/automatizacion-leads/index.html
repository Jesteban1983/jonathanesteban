Estudio de Caso #3

Agentes de IA autónomos & Pipeline n8n

Cómo conectar 8+ herramientas de Google, Telegram y n8n con agentes inteligentes para captura y cualificación automática de leads.

La Solución Tecnológica

Implementación del agente ClawMate con servidor MCP Composio, automatización de publicación de contenido multimedia en YouTube/n8n y alertas inmediatas al dispositivo móvil vía Telegram Bot.

Stack Tecnológico

Python OpenClaw Composio MCP n8n Telegram Bot API Google APIs Supabase GitHub Actions

Combinación de agentes autónomos, orquestación MCP y automatización low-code para construir un pipeline completo de captura y cualificación de leads.

Arquitectura del Sistema

El flujo de datos sigue una cadena de componentes orquestados:

  • ClawMate Agent — Agente autónomo que interpreta comandos y contexto mediante LLM.
  • Composio MCP Server — Servidor de protocolo MCP que expone herramientas conectadas como servicios.
  • Tool Registry — Registro centralizado de herramientas disponibles (Google Sheets, Gmail, Calendar, YouTube).
  • n8n Webhook Pipeline — Orquestación low-code que encadena triggers, transformaciones y acciones.
  • Telegram Bot — Canal de alertas y notificaciones en tiempo real al dispositivo móvil.
  • Google Workspace — Integración nativa con Gmail, Drive, Calendar y YouTube Data v3.

Flujo de Automatización

  1. Webhook de n8n recibe trigger (nuevo lead, email, formulario)
  2. Agente ClawMate analiza con contexto LLM
  3. Composio MCP ejecuta herramientas conectadas (Google Sheets, Gmail, Calendar)
  4. Lead cualificado se registra en Supabase
  5. Notificación push vía Telegram Bot
  6. Reporte diario automatizado

Resultados

  • Captura y cualificación 24/7 sin intervención humana
  • Integración con 8+ herramientas de Google Workspace
  • Alertas en tiempo real al dispositivo móvil
  • Pipeline completo en n8n con recuperación ante fallos
