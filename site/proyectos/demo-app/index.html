Demostración de App en Vivo

Prueba la lógica de procesamiento dinámico en cliente asistida por simulación de Agente de IA.

Acerca de esta Demo

Esta aplicación interactiva simula un pipeline de procesamiento de agente de IA directamente en el navegador. Implementa gestión de estado, procesamiento asíncrono y respuestas simuladas de LLM para demostrar cómo un agente autónomo interpreta comandos, ejecuta pasos secuenciales y devuelve resultados estructurados — todo sin necesidad de un backend.

Tecnologías Implementadas

JavaScript (ES Modules) TypeScript CSS Custom Properties Web Components Async/Await State Management

Características

  • Simulación de procesamiento asíncrono con estado
  • Interfaz responsiva con modo oscuro/claro
  • Logs de ejecución en vivo
  • Manejo de errores y estados de carga
